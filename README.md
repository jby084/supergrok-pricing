Lite 和标准档之间没有“功能有无”的差别，差距在用量额度和模型权限——$30 买的是更多次的同一样东西。所以 Lite 适合先花小钱验证自己到底用不用得上。

## 付费之后多了什么，额度怎么算

先说免费版的现状：图片和视频生成已经整体挪进付费档，免费用户基本只剩文字对话，文本额度大约每两小时十次左右（滚动窗口计算）。偶尔问问题够用，只要碰生图或视频就会撞墙。

SuperGrok 标准档给到的东西：

- 用量上限是免费版的 20 倍，响应更快，不容易聊几句就限流；
- Grok Imagine 生图和视频，720p 画质，能一次生成 30 秒的连贯故事；
- 长对话、长文档任务的承载长度是免费版的 5 倍；

额度算法有个容易忽略的点：付费档现在采用“共享周额度”机制，聊天、Imagine、语音、Build 这些功能共用一个每周额度池。生成视频、跑长任务这类吃算力的操作，消耗速度比普通聊天快得多。当前用量百分比和重置时间，在账户设置里的 Usage 页面能看到。

**确认开通**：付款后刷新官网或重新登录，进账户设置的订阅页，看到 SuperGrok 标识就算生效。偶尔有几分钟的同步延迟，等一等再刷新即可；超过半小时还没动静，先联系付款渠道的客服核实订单，别急着重复下单。

**取消订阅**：原则是在哪付的钱，在哪取消。官网订阅在官网的账单设置里操作；iOS 内购在 Apple ID 的订阅管理里；Android 内购在 Google Play 订阅里。取消只是停掉下一周期的续费，当前已付周期不退，会一直用到周期结束。别用删除 App 或删除账号的方式“取消”——那是两回事，删账号还会连聊天记录一起清掉。

**退款找谁**：官网订阅找 xAI，iOS 找苹果，Android 按 xAI 的退款表单流程走；X 那边的 Premium 订阅一般不予退款，除非当地法律要求。留好支付收据，比截图升级页面有用得多。
